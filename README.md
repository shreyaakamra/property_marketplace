# Property Marketplace

A web-based property marketplace developed using **PHP, Laravel, and Blade** as part of my development internship at Xlligent.

## Overview

Property Marketplace is a website designed to help users explore property listings and view relevant property details through a structured, user-friendly interface.

## Tech Stack

- **Backend:** PHP, Laravel
- **Frontend:** Blade, HTML, CSS, JavaScript
- **Architecture:** Laravel MVC

## Features

- Multi-page website structure
- Property listing and detail pages
- Reusable Blade layouts and components
- Laravel routing and backend integration

*Note: Features are subject to ongoing development.*

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/shreyaakamra/property_marketplace.git
   ```

2. Navigate to the project directory:

   ```bash
   cd property_marketplace
   ```

3. Install dependencies:

   ```bash
   composer install
   ```

4. Configure your environment variables using the `.env` file.

5. Generate the application key if required:

   ```bash
   php artisan key:generate
   ```

6. Start the development server:

   ```bash
   php artisan serve
   ```
